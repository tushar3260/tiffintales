# 🍱 Tiffin Tales

**Homemade. Delivered. Loved.**

Tiffin Tales is a full-stack MERN web application that connects customers with homemade tiffin and meal providers. The platform makes it easier for users to discover home-cooked food, explore available meal options, and place orders through a simple and user-friendly interface.

## 🚀 Live Project

**Website:** https://tiffintalesindia.me/

**Frontend:** https://tiffin-tales-nine.vercel.app/

## ✨ Features

* 👤 User registration and authentication
* 🔐 Secure login and authorization
* 🔎 Browse and explore tiffin services
* 🍱 View available meals and tiffin details
* 🛒 Order management
* 📍 Location-based tiffin discovery
* 👨‍🍳 Tiffin provider / kitchen management
* 📦 Order tracking and management
* ☁️ Cloud-based image storage
* 📱 Responsive UI for desktop and mobile devices
* 🔗 REST API based frontend-backend communication

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* MongoDB
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/tushar3260/tiffintales.git
cd tiffintales
```

### 2. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Setup Backend

Open another terminal:

```bash
cd backend
npm install
npm start
```

### 4. Environment Variables

Create a `.env` file in the backend directory and configure the required environment variables.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
```

> Never commit real API keys, passwords, database credentials, or other secrets to GitHub.
